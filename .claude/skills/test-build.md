# Test — интеграционный полигон

## Что это

`test` — одноразовая ветка для тестирования на девайсе. В неё смерджены `origin/master` плюс все активные фичи, чтобы гонять их вместе в реальном использовании, пока каждая по отдельности ещё не дозрела до релиза.

Ключевое свойство: **у `test` нет истории.** Она не мерджится и не ребейзится — она выбрасывается и собирается заново на каждом прогоне. Поэтому фича, ушедшая в `master`, просто выпадает из набора вместо того чтобы конфликтовать сама с собой.

Модель взята из воркфлоу самого git — ветка `pu` (proposed updates), `man gitworkflows`.

## Пересборка

```bash
scripts/rebuild-test.sh
```

Скрипт фетчит `origin`, пересоздаёт `test` от `origin/master` и мерджит в неё каждую активную ветку через `--no-ff`. Перед мерджем печатает состав — сверь глазами, что там нет ничего забытого.

Требует чистого рабочего дерева: иначе незакоммиченные изменения переехали бы на `test` и поломали мерджи.

## Отбор веток — opt-out

Берутся **все** локальные ветки, чьих коммитов ещё нет в `origin/master`. Ничего помечать для включения не надо: завёл ветку — она в сборке.

Исключить ветку:

```bash
git config branch.<name>.notest true
```

Флаг лежит в `.git/config` — локальный, не коммитится, исчезает вместе с веткой.

Отдельная проверка «а вдруг ветка уже в мастере» не нужна: `--no-merged origin/master` и есть эта проверка. Забытый флаг сборку не сломает.

## Конфликты

Включён `git rerere` — он запоминает, как разрулен конфликт, и при следующей пересборке применяет то же решение молча. Первый раз руками, дальше само.

При конфликте скрипт останавливается. Разрули, сделай `git commit` (именно коммит записывает решение в rerere), затем запусти скрипт заново — пересборка пойдёт с нуля и повторит решение автоматически.

Кэш rerere лежит в `.git/rr-cache/`, он локальный и на другую машину не переезжает.

## Чего не делать

- **Не коммитить в `test` напрямую.** Коммит потеряется при следующей пересборке. Нашёл баг при тестировании — фикс в ветку фичи, потом пересборка. Заблокировано хуком `.githooks/pre-commit`.
- **Не пушить `test`.** Ветка чисто локальная. Заблокировано хуком `.githooks/pre-push`.
- **Не мерджить `test` никуда.** Она лист, а не предок: в ней лежат недотестированные фичи вперемешку.
- **Не мерджить `master` в `test`.** Незачем — база и так берётся от свежего `origin/master` на каждом прогоне.
